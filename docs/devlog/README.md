# Devlog

Ein kurzes Entwicklertagebuch zu Arborist. Ein Eintrag pro Arbeitstag, geschrieben für Leute, die einfach mitlesen wollen – nicht für Entwickler, die den Code verstehen müssen.

## Regeln für Einträge

- Datei pro Tag: `JJJJ-MM-TT.md`. Mehrere Sitzungen am selben Tag landen im selben Eintrag.
- Kurz: 200 bis 500 Wörter. Was haben wir uns überlegt, was entschieden, was gelernt, was kommt als Nächstes.
- Verständlich ohne Vorwissen. Fachbegriffe kurz erklären oder weglassen.
- Ehrlich: Sackgassen und verworfene Ideen gehören dazu.
- Nichts Privates: keine Namen, Zugangsdaten, Hostnamen oder persönlichen Inhalte.
- Front Matter oben, damit sich Einträge später automatisch veröffentlichen lassen:

```yaml
---
title: "Kurzer Titel"
date: JJJJ-MM-TT
tags: [arborist, claude-code, playdate]
summary: "Ein Satz, worum es heute ging."
---
```
